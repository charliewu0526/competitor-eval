# [G3] 分层人工抽查（10% / 100% / 100%）

Label: ready-for-agent
Covers user stories: 16, 18

## What to build
人从「每环节签字闸门」挪到「路径外抽查员」。人只做异步分层抽查：普通任务随机 10%、矛盾项（三模型分歧标红）100%、高风险结论 100%。系统不因等签字而卡住——抽查是事后异步的，不阻塞主流程。

## Acceptance criteria
- [ ] 抽查队列按规则采样：普通随机 10%、矛盾 100%、高风险 100%
- [ ] 抽查为异步，主流程入库不等待人工处理
- [ ] 矛盾项（E3 标红）必然进入 100% 抽查队列
- [ ] 抽查结果可回写并触发 G2 的「抽查异常 → 重校准」
- [ ] 看板/队列能列出待抽查项及其分层原因
