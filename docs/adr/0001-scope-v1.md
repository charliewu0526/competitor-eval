# ADR-0001 — 第一版范围：评测引擎 + Bug + 产品机会，情报 Pipeline 砍到 v2

- 状态：已接受
- 日期：2026-06-24

## 背景

原始构想有三条 Pipeline：①Bug ②产品机会 ③竞品情报。是否第一版全做？

## 决策

第一版只做 **评测引擎 + 它直接长出来的 ①Bug 和 ②产品机会**。③竞品情报推迟到 v2。

## 理由

1. **依赖方向**：①②都长在「评测」这棵树上（①是评测副产物，②是评测结论）；③不依赖评测，是独立的爬虫+人工判断系统。评测引擎是地基，先修地基。
2. **情报追踪到的新功能，最终仍要靠评测验证强弱** —— ③是地基上的水龙头，不是地基。
3. **技术上③是另一摊活**（多源抓取、定时、反爬），与评测引擎几乎不共享代码；混做等于同开两个工程。
4. 原始风险①自陈「别一上来追求全量」——三条全做即全量。

## 后果

- v1 代码、词汇、看板只围绕评测引擎 + ①② 组织。
- ③ 若 v2 启动，做成独立子项目，不与评测引擎共用代码。
