# ADR-0005 — 校准机制：打分与找错分家，偏移档案先记录不自动改分

- 状态：已接受
- 日期：2026-06-24
- 关联：ADR-0004（评分框架）、T5 黄金集校准

## 背景

实战观察（来自历史项目）：评审模型有系统性宽严偏差——DeepSeek 整体偏严、Gemini 整体偏松；且 DeepSeek 的低分常是「真抓到缺陷」（precision 高）。宽严偏差是噪声，缺陷检出是信号，二者缠在一起。

## 决策

**把「打分」和「找错」彻底分家：**

1. **打分（→排行榜）**：用稳健聚合（中位数 / 截尾平均），模型性格偏差不带歪排行榜。
   - 注意：不能用简单中位数把某个总是最低分的模型（如 DeepSeek）系统性丢弃——需结合偏移档案，规则待 T5 后细化。
2. **找错（→Bug / 产品机会 pipeline）**：任何模型写的具体缺陷，**不管打分高低、不管谁打的**，只要缺陷有效就单独抽出入库。DeepSeek 的「严」通过缺陷清单兑现价值，而非通过压分。

3. **偏移档案**：用 T5 黄金集（人工已打标准分的样本）实测三模型对新面板（DeepSeek+GLM+Claude）各自的平均偏移。
   - **第一版只记录偏移档案作为看板元信息，不自动去偏改分** —— 数据不足时自动校准易矫枉过正，会抹掉 DeepSeek 真信号。先观察，攒够数据再议。

## 关键约束

- **经验不能跨模型搬**：「Gemini 偏松」是旧面板经验；新面板无 Gemini（用 Claude）。谁偏松/各偏多少必须对新面板重新实测。

## 后果

- 缺陷检出逻辑独立于聚合打分逻辑（呼应三 pipeline 设计）。
- 聚合规则在 T5 校准产出偏移档案后才最终冻结。
