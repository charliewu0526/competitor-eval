# 标准 Prompt:统一一条 + 禁用任何产品专属语法(中立母语)

竞品横评最易被一句话击穿:「你们是用对自家有利的 prompt 测的」。同一任务目标,若 Prompt 照 Violoop 的提示习惯写,Violoop 天然占优,竞品在用「别人的母语」答题;盲评盲得掉「谁是自家」,盲不掉 Prompt 本身的偏向。三条路:①每产品一条适配 prompt(公平发挥最佳,但 N 条是否等价无法保证,改写又引入人为偏向);②完全同一条(可复现,但风格可能偏向某产品);③统一一条但禁用任何产品专属语法。

决定走③:一道题一条**标准 Prompt**,用最朴素的自然语言描述任务目标,**禁止**任何产品专属语法/结构化技巧/触发词——谁都不能靠「母语优势」得分。可复现性与公平性兼得,代价是「都不发挥最佳」而非「都发挥最佳」。

## 代价

测的是「各产品对朴素指令的理解与执行」,不是「各产品被高手调教后的上限」。若某产品的价值恰恰在其专属交互范式(如 Codex 的代码化描述),这套会低估它——这是刻意选择:横评要的是同起跑线的可比性,不是各自巅峰。上限对比留给 capability-probe 专项路径另做。
