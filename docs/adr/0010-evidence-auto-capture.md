# ADR-0010 — 证据自动采集：三级，优先日志，无需人工录屏

- 状态：已接受
- 日期：2026-06-25
- 关联：ADR-0004（末态证据→客观层，过程证据→S5）

## 背景

「人工录屏取证」效率太低，不可持续。证据采集应全自动。

## 决策

### 两种用途分采

- **末态证据**（→客观层）：脚本自动抓——读文件 / 查库 / 自动截最终图。**不用录屏。**
- **过程证据**（→S5 体验分）：按轻→重三级，优先用轻的。

### 过程证据三级（优先级从高到低）

1. **结构化日志 / transcript（最轻，首选）**：竞品自出日志（如 OI transcript）直接用，文本可让 AI 直读。
2. **关键帧截图（中，自动）**：无日志则在关键动作处自动截帧（Vio computer-use 本就能自动截）。
3. **全程录屏（重，兜底）**：仅黑箱竞品用；macOS `screencapture`/`ffmpeg` 脚本自动开停，**全程无人**。

### 诚实约束

- 日志只可信「它做了什么」（行为轨迹），**不可信「做成了没」**（结论仍以末态硬验为准，呼应 OI 谎称完成）。
- 加 `evidence_source` 字段：`log | screenshot | screen-recording`（同 cost_source 思路）。

## 后果

- 跑测脚本负责自动采集；无任何人工录屏环节。
- 无过程证据 → S5 留空（ADR-0004）。
