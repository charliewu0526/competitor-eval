# ADR-0002 — 第一版只支持「本地桌面 App 操作」环境

- 状态：已接受
- 日期：2026-06-24
- 关联：ADR-0001（范围）

## 背景

竞品横跨本地桌面 / Web / 云。每多支持一类环境，就要多写一套「喂题 + 读结果」的对接代码（原始风险①）。第一版先吃哪类？

## 决策

第一版评测引擎只支持 **本地桌面 App 操作**。Web / 云端环境推迟到 v2。

## 理由

1. **复用全部已有资产**：微信题、Vio run、Open Interpreter run、rubric、客观断言层，全是本地桌面的。换环境=推倒重来。
2. **本地桌面是 Violoop 主场**：Vio 是通用桌面助手，第一版就该测最该赢的主场。
3. **执行风险①「别一上来全环境」**：先窄后宽。

## 后果

- **能力域字段退化为一个布尔** `can_operate_local_desktop`（见 CONTEXT）。
  - Vio=true, Open Interpreter=true, Manus（云端）=false → 本地桌面题自动判 cannot-reach，不参赛。
- 纯云端竞品（如 Manus）第一版进不来，等 v2 支持 Web 环境。
- **平滑扩展保证**：将来扩到多环境时，把布尔升级成单元素清单 `["local_desktop"]` 即可，不算推倒重来。
