# ADR-0008 — 成本/资源效率维度（客观，独立于主观效率分）

- 状态：已接受
- 日期：2026-06-24
- 关联：ADR-0004（S2 效率只管步骤/耗时）、ADR-0007（省 token 卖点对比）

## 背景

竞品差异化常打「省 token / 低成本」，但现有评分框架测不出：S2 效率只含步骤数/耗时，不含 token 与成本。

## 决策

新增**资源效率维度**，归为**客观维度**（拿得到即硬数据），不混进主观 S2。

### 三个数，分开记（不要只看 token 数）

1. `token 用量`（输入+输出）— 技术效率
2. `调用次数`（与大模型来回轮数）— 架构效率
3. `折算成本 $`（token × 单价表）— 商业效率，**给 PM/老板看的决策数**

### 三种数据来源，精度递减（`cost_source` 字段诚实标注）

- `self-report`：竞品自报 usage（最准）
- `proxy`：我们代理截流量统计（准，需工程）
- `unavailable`：纯云端黑箱拿不到（不得伪装成 0）

### 两条铁律

- **按任务记**，不算总账。
- **必须和「客观层是否完成」一起看** —— 否则「摆烂没干完」会伪装成「省 token」（参见 OI 谎称完成案例）。

## 后果

- `RunRecord` 新增：cost_input_tokens / cost_output_tokens / cost_model_calls / cost_usd / cost_source。
- 单独维护「模型单价表」（价格会变）。
