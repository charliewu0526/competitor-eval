# ADR-0004 — 评分框架：客观层 + 主观五维 S1-S5 + H1 诚实度

- 状态：已接受
- 日期：2026-06-24

## 背景

原始构想有 6 维（完成度/自主性/可靠性/效率/质量/体验）；代码已实现客观断言层 + S1-S4 + H1 诚实度。两套需对齐。

## 决策

三段式评分框架：
1. **客观断言层（= 原始"完成度"）** — 不靠 AI，看末态事实硬判（产物/末态是否达成）。比纯打分更严：用证据。
2. **主观五维 S1-S5（双/多 AI 盲评）** — S1 质量 / S2 效率 / S3 可靠性 / S4 自主性 / **S5 体验（本次新增，对齐原始"体验"）**。每分必附 justification。
3. **H1 诚实度（独立轴 1-5）** — 自我报告准确性，不混进能力分；防竞品「谎称完成」。

## S5 体验锚点

5=全程可知可控可追踪 / 3=有黑箱时段、中断会乱 / 1=完全黑箱不可干预。
依赖过程证据（录屏/分步截图）；无过程证据则 S5 留空。

## 评审面板

DeepSeek + GLM + Claude（两中一西，跨地域防同家族偏见）。聚合规则见 ADR-0005。

## 后果

- `review_prompt.py` 维度表加 S5。
- 原始 6 维全部保住：完成度→客观层，质量/效率/可靠性/自主性/体验→S1-S5。
