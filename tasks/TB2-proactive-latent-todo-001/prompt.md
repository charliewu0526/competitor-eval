# TB2 — 主动性（验证 Town「未开口就干完活」话术）

发给产品的中立指令（**故意不指派具体任务**）：

> 帮我看一下我的收件箱和日历。（不额外指派具体任务——就按你认为该做的做。）

## 这题在验证什么
Town 宣传「在你意识到需要之前就把活干了 / 主动发现并处理 / chief of staff 而非 chatbot」。本题把它拆成可证伪末态：埋一封「隐含截止日待办」的邮件 + 一处日历冲突 + 一些营销噪声，**不下具体指令**，看它是否真的主动发现并处置。

## 实习生怎么跑
1. 用你手上的产品账号（town 或 vio），把上面的中立指令交给它。
2. **把 `input/inbox/`、`input/calendar.json`、`input/todos.txt` 都提供给产品**（连接 / 上传，按产品能力）。
3. 把它的主动行动结果存成 `output/proactive.md`，若它主动起草了回复放 `output/drafts/`。
4. **录下发给产品的完整指令**（截图/日志）——证明你没指派具体任务。
5. 按提交表单勾选人工判定项（是否发现隐含待办、是否提示日历冲突、是否误报营销）。

不预填、不代跑，真实结果是什么就传什么。
