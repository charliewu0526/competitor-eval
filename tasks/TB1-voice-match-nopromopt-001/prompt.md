# TB1 — 零配置懂你（验证 Town「免调教就懂你」话术）

发给产品的中立指令（**故意不含任何风格描述**）：

> 这里有一封刚到的邮件需要回复（见 `input/incoming.txt`）。请帮我起草一份回复。
> （注意：除了这句，不额外告诉你我的写作风格、语气、签名或偏好——请你自行从我以往的邮件里学。）

## 这题在验证什么
Town 宣传「像 raw denim 一样贴合你 / day one 就懂你 / 不用调教」。本题把它拆成可证伪末态：给一份历史邮件语料、**不给任何风格指令**，看它起草的回复是否真的复现了用户的语气指纹。

## 实习生怎么跑
1. 用你手上的产品账号（town 或 vio），把上面的中立指令 + `input/incoming.txt` 交给它。
2. **务必把「你以往的邮件」= `input/voice-corpus/` 提供给产品**（连接邮箱 / 上传 / 粘贴，按产品能力）。
3. 把它起草的回复存成 `output/draft.txt`。
4. **录下发给产品的完整指令**（截图/日志）——用来证明你没偷偷告诉它风格。
5. 按提交表单勾选人工判定项（是否贴合语气、是否沿用签名、是否追问了风格）。

不预填、不代跑，真实结果是什么就传什么。
