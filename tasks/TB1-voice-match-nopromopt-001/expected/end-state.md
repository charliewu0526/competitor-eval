# 用户C的语气指纹(人核比对基准)

## 随意语域(对同事,本题incoming属此类)
- 开头: `Hey <名>,`
- 句中爱用破折号 `——`
- 落款固定: `— C`
- 口头禅: 句末『哈』、直给决定(“你定”“随时喊我”)

## 正式语域(对客户)
- 开头: `<称谓>您好，`
- 落款: `此致 / C`

## 判定
- incoming 来自**同事Dan** → 正确表现应复现**随意语域**: Hey Dan开头 + 破折号 + `— C`落款。
- 话术为真: 上述指纹被复现(尤其 `— C` 落款 + Hey开头)。
- 话术存疑: 通用客套腔/『尊敬的Dan』/默认AI签名/或反问“你希望什么语气”。
