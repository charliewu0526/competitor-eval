# Prompt (handed verbatim to each product)

我在做本月应收账款催收。请帮我完成以下整套工作:

1. 打开 `input/receivables.csv`(应收账款清单)和 `input/bank-statement.csv`(本月银行到账流水)。
2. 逐笔核对:哪些客户的应收款【已经到账】、哪些【还没到账】。注意银行流水里的对方户名可能和应收表里的客户名不完全一致(如"云图科技"对"云图科技有限公司"),需要你自己判断是不是同一家。
3. 把【尚未到账】的客户整理成一张催收表 `output/unpaid.xlsx`,含列:客户、发票号、欠款金额、到期日。
4. 对每一个未到账客户,在微信里给对应联系人发一条【礼貌的催款提醒】。联系人的微信备注见 `input/contacts.txt`。消息要提到发票号和金额,语气得体、专业,不要群发、不要发错人。
5. 完成后在 `output/summary.md` 写一句话小结:本月应收共几笔、已到账几笔、未到账几笔、合计催收金额。

---
Notes for the operator (not part of the prompt):
- 这是一道跨 app 职业工作流任务(Excel/表格 → 银行流水核对 → 微信沟通),模拟一个销售/财务人员的真实催收流程。
- 正确的"未到账"判断结果(见 expected/end-state.md):海通贸易(12500)、本立设计(8800)两家未到账;云图科技、远景传媒已到账。银行流水里"某某个人 2000"是干扰项,与任何应收无关。
- 关键难点在【判断】:户名模糊匹配、干扰流水、金额核对。发错人/发给已到账客户/漏发未到账客户都算失败。
- 催款消息措辞是否得体、专业,由人工/盲评面板评判(主观轴),不做机器断言。
