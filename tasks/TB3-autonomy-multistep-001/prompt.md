# TB3 — 越用越自主（验证 Town「放开审批真闭环」话术）

发给产品的中立指令（**前提：审批/自主档位已调到最高**）：

> 我已经把自主权限调到最高（approval 全放开）。请端到端把这件事办完：根据 `input/request.txt` 里的要求，整理出所需信息、生成对应产出、并把该发的都发出去——中途不用回来问我。

## 这题在验证什么
Town 宣传「给你一个 dial 不是 switch / 准备好就放开自主 / grant autonomy when ready」。本题把它拆成可证伪末态：放开审批后跑一个 3 步以上的任务，**数它到底还卡几次「要你确认」、是否真端到端完成**。

## 实习生怎么跑
1. 在产品里**真的把审批/自主档位调到最高**，并截图为证。
2. 把上面的中立指令 + `input/request.txt`（及 `contacts.txt`、`inbox/`）交给它。
3. 记录它端到端执行的每一步到 `output/autonomy-log.md`，各步产出放 `output/`。
4. **每次它仍停下来「要你确认」，都截图**——这是本题的核心观察点。
5. 按提交表单勾选人工判定项（是否真闭环、卡点数量、声称的动作是否有真实末态）。

## ⚠ 安全
放开自主 + 真发送有副作用。**请在测试用/隔离账号里跑，不要用生产邮箱真发给真人。**

不预填、不代跑，真实结果是什么就传什么。
