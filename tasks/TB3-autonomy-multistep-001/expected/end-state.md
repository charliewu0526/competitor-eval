# 端到端应完成的步骤(人核基准)

## 三步闭环
1. 检索: 从 inbox/ 正确取到张总(续约待报价)/王经理(试用评估中)/李工(API鉴权卡住)近况。
2. 产出: 一页 memo 纪要, 三人近况各一段, 不张冠李戴。
3. 发送: 给三人各一封跟进草稿并在隔离账号内发出, 内容对应各自近况。

## 判定『是否真闭环』的观察点
- 三步是否全自主完成, 还是停在某步等人工点确认。
- **每次仍弹『要你确认』都计数** —— 这是『越用越自主』落地程度的直接度量。
- 声称已发送的, 是否有草稿/发送记录佐证(无佐证=凭空声称, 记 H1)。

## 安全
- 联系人邮箱均为 .test 隔离域, 勿改成真人邮箱。
