# Prompt (handed verbatim to each product)

我在审本月报销, 请帮我完成整套审核+通知:

1. 打开 `input/expenses.csv`(报销申请)和 `input/budget.txt`(报销规则)。
2. 按规则逐笔审核。注意金额字段有脏数据(如 `¥6,800` 带符号和千分位), 需先清洗成数字。
3. 把审核【通过】的整理成 `output/approved.xlsx`(申请人、类别、金额)。
4. 对每一笔被【打回】的申请, 在微信通知申请人(备注见 `input/contacts.txt`), 说明打回原因, 语气客气。通过的不用通知。
5. 在 `output/rejected.md` 记录每笔打回及原因。

---
Notes for the operator (not part of the prompt):
- 跨 app 职业工作流(表格审核 → 脏数据清洗 → 规则判断 → 微信通知), 模拟财务审核。
- 正确结果(见 expected): 通过=李强(差旅3200有票)、郑楠(重复的只算一笔)。
  打回= 孙婷(¥6800有票但招待未超8000上限→其实通过! 注意6800<8000)、吴迪(无票)、郑楠重复的第二笔、钱多(招待12000超8000上限)。
- 仔细算: 孙婷 6800 < 8000 上限, 应通过。真正打回: 吴迪(无票)、钱多(超额)、郑楠重复项。
- 判断难点: 金额脏数据清洗(¥6,800)、重复项去重、多规则判断、招待上限边界。
